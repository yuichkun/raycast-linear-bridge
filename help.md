# Set Up Your Linear API Key

1. In Linear, open **Settings → Account → Security & Access → Personal API keys**.
2. Create a new key and copy it.
3. Paste it into **Linear Personal API Key** below.

**Do not restrict the key to specific teams.** Linear Bridge reads and creates issues across every team you belong to, so a team-restricted key will silently miss issues in the teams it excludes.

There is no separate "who am I" setting — Linear resolves the key's owner itself, so swapping the key is all it takes to switch accounts.
